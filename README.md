# Hande Kaya - CV Repository

This repository stores role-specific versions of my CV, along with changelogs and dated updates.

## CV Versions

- `backend/` → Backend-focused CV
- `frontend/` → Frontend-focused CV
- `general/` → General software engineer CV
- `master/` → Master source containing all experience, projects, skills, and bullet banks
- `archive/` → Older versions and exported backups

## Workflow

1. Update `master/master_resume.md`
2. Copy relevant content into the role-specific CV
3. Update the related `CHANGELOG.md`
4. Export PDF if needed
5. Commit changes with a clear message

## Naming Convention

Examples:
- `hande_kaya_cv_backend_2026-04.pdf`
- `hande_kaya_cv_frontend_2026-04.pdf`
- `hande_kaya_cv_general_2026-04.pdf`

## Notes

- Keep the editable source in Markdown
- Use role-specific wording depending on the application
- Keep changelogs short and practical
